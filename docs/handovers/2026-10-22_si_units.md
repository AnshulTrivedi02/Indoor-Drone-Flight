# Handover 2026-10-22: SI units on the plots and in the results walkthrough

User request (verbatim): "are you able to make sure all the plots and the results walkthrough are all in si units, not cm, mm etc".

## Decisions applied
- Lengths in metres, times in seconds, angles stay in degrees, speeds m/s.
- km values become metres rounded to the nearest 1000 m (the precision of the source), with the digits grouped by a
  narrow no-break space (U+202F), the SI group separator, for numbers of five or more digits: `29 000–40 000 m`.
- Precision is not increased: 1 dp mm becomes 4 dp m, 0 dp mm becomes 3 dp m, 1 dp cm becomes 3 dp m, 1 dp ms becomes 4 dp s.

## Method (exactness kept)
- `rd_si(v, n, k)`: an exact decimal shift of the stored value by 10^k, then ONE ROUND_HALF_UP rounding at the printed
  precision. It is never a float multiply. With k = 0 it equals `rd()`. `rd()` itself is unchanged, and its SHA check still holds.
- `si_str(s, k)`: every number in a numbers.md or table string is shifted exactly as a Decimal. SI checks compare
  `rd_si(...)` against `si_str(source, k)` by string equality. The check label states the factor ("numbers.md mm × 10^-3").
  The native-unit "shown in"/numbers.md substring checks are kept, because the tables and numbers.md keep their units.
