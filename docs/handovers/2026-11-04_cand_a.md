### Architecture

- Shared code (`rd`, `rng`, `sim_path`, `cl_clock`, `cl_yaw_err`, `cl_meta`, `C`/`MK`/`TRUTH`/`EST`/`HALF`/`WIN`) is
  **ast-parsed from `eval/figs_thesis.py`**, not executed as a script and not imported - the same technique
  `eval/figs_walkthrough_flights.py` uses, so this script cannot silently drift from the thesis figures' own values.
- `cached()`/`ex_cl()`/`ex_room()`/`ex_sim()`/`ex_xkf1()`/`_bag_open()`, `aligned`-adjacent helpers (`to_NE`, `NE`,
  `frame_ok`, `unaligned`, `gt_enu`) are COPIED from `eval/figs_walkthrough_flights.py` (itself copied from
  `eval/figs_thesis_drift.py`/`_results.py`), not invented.
- Its own `save()`/`check()`/`cite()`/`write_caption()` mirror `eval/figs_thesis.py`'s, writing to
  `docs/thesis/figures_thesis/candidates/` instead (NOT `thesis_style.write_caption()`, which hard-codes
  `figures_thesis/captions/` - using it would have perturbed `caption_verdict_check`'s file count).
- A local copy of the D113 banned-word regex self-checks every caption body before `save()` writes it (the
  coordinator's `caption_verdict_check.py` does not yet scan `candidates/`, per the group brief).
- **Height autocrop** (`save()`): several candidates lock an axes box to a 1:1 data aspect (`adjustable="box"`),
  which leaves a lot of dead vertical margin in a fixed-height figure - the same mechanism the restyle's R3/R5 fix
  addressed. Rather than hand-tuning `figsize` per figure, `save()` crops the SAVED bbox to the figure's own actual
  content height, at the FULL declared width (`0` to `TEXT_WIDTH_IN`) - every PDF is still exactly 453.6 pt wide
  (confirmed: `pdfinfo` on all 20), unlike `bbox_inches="tight"` (which the restyle banned because it also changes
  the width).
