No interpretation, comparison or ordering of estimators is made anywhere in this file (counts and citations only).

**Stage 1b (D111, binding):** Stage 1 withheld raw values per CELL on a 2° heading-of-first-5m check; 69/154 cells were withheld. D111 ruled that per-cell gate a harness design error — it was rejecting the estimator's OWN early yaw error, which is the quantity raw error exists to show — and replaced it with frame validation run once PER ESTIMATOR (EKF3/UKF/FGO), never per cell: (i) take-off origin |NE| < the tolerance on every cell of that estimator, and (ii) the original strict check (origin + heading-of-first-5m) passes on at least one cell of that estimator. If both hold, raw values are published for ALL of that estimator's cells. The per-cell strict result is kept as `strict_frame_check_info` in the json — informational, never a per-cell gate — and each cell's early heading offset is published below as its own DESCRIPTIVE column, never used to withhold anything. Nothing else about the error model changed (same association, window, frame relabel and rounding as Stage 1); the evo -a reproduction GATE is unchanged and still a per-CELL stop condition.

**Frame convention** (identical to Figure 4.1c / R5, `docs/thesis/figures_thesis/index_drift.md`, re-derived for this scope — not imported, since that script is scoped to one flight): EKF3 traj + truth are (N, E, D) -> (N, E, U) = (col1, col2, −col3). UKF/FGO truth files are ENU (E, N, U) -> (N, E, U) = (col2, col1, col3). UKF/FGO estimate files are the estimator's own frame, x = take-off heading (North), y = West, z = up -> (N, E, U) = (col1, −col2, col3). No other rotation, offset or scale. yaw0 = 0.0 for every cell in this scope: `src/estimators/ukf_core.py:318` (`x[6], x[7], x[8] = roll0, pitch0, 0.0`, unconditional); `src/estimators/fgo/fgo_core.py:120` (`init(yaw0=0.0)` default), and `src/estimators/fgo/fgo_replay.py:134` passes `np.radians(F_YAW0_DEG)` only when the `F_YAW0_DEG` env var is set — grepped (`eval/diag/plainwall_trace/*.sh`): it is set only by the plain-wall initial-yaw-sensitivity trace runs, which are NOT in this scope (different output directories, excluded by construction — this script reads `ukf_heading`/`fgo_heading`/`fgo_heading_yawrate`, never the `F3*`/`regress*`/`PATnocap` sensitivity variants).
