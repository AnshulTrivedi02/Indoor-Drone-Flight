## Experiment 4 (O) check

**SKIPPED.** `src/estimators/room_ukf_ipls_replay.py` lists `--gnss` in its `REFUSED_FLAGS` and exits before doing anything else if it is passed. Its `read_events()` has no `"gnss"` event kind (it only emits `imu`/`rng`/`flow`/`att`/`tag`), and `ukf_ipls.py` has no GNSS measurement model or op type. Supporting `--gnss` would require a new event kind, a new recorded op (`U.update_gnss`'s linearisation in `ukf_ipls.py`), and the GNSS-mode branch of `room_ukf_replay.py`'s anchoring logic (`O_r*` use `--gnss`, not tags) to be duplicated into the IPLS replay -- that is new estimator code, not a flag pass-through, so per the task's own instruction this was not done and O is not run.
