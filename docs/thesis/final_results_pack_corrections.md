# Corrections summary (final results pack, 2026-10-11)

Every correction applied to the simulation results, in the order applied. This file is the source of Table T2 in
`docs/thesis/final_results_pack.pdf`. It summarises; it does not restate. Values are quoted from METHODOLOGY.md,
`docs/thesis/numbers.md` and the named `eval/results/` files, and none is recomputed here. evo = evo -a (cruise), m.
† = runaway magnitude (order of magnitude only).

**Attribution rule (ruling 2026-10-10, "the attribution study is STOPPED", and "O attribution stated as a PARTIAL
ATTRIBUTION FINDING"):**
- The corrections applied in one batch are **applied jointly, not attributed**. This covers the consolidated re-fly,
  items 3–7 below, and the final re-run, items 15–18.
- There are three exceptions:
  - the directly traced plain-wall case;
  - the ruled O partial attribution;
  - `dsn_tex_r2`, attributed to the jitter fix by elimination.
- An "ablation pair" is a before/after comparison where only that correction changed. "Evidence at discovery" is the
  measurement that exposed the defect. It is NOT a headline attribution.
- **Scope:**
  - MODEL: an estimator, sensor or vehicle model;
  - CONFIG: an ArduPilot or simulator setting;
  - DATA: a data-handling rule;
  - PORT: a flight-code port bug, not a model change;
  - SCORER: an evaluation-code bug;
  - ANALYSIS: an analysis definition.
