E02. Extension E3 (wrong tag IDs): the FGO's live path, clean reference and two 1% runs.

Extension E3 (wrong tag IDs), one flight, the FGO's live path in orange against the true path in grey and the 8 true tags as grey diamonds, raw, in tag 0's frame, equal scale. (a) no wrong IDs: the live path stays on the square. (b) 1% wrong IDs, one seed: the live path does not diverge, but is pulled inward, off the square. (c) 1% wrong IDs, a different seed: the solver diverges; the path is drawn only up to shortly after the divergence, after which the live estimate leaves the room and is not shown. A run counts as diverged only on a solver failure (a keyframe the solver could not solve, or a non-finite estimate), not when its error is large.
