Experiment 5 (tag hold), one flight per flying estimator: EKF3 in blue, UKF in teal, FGO in orange, each on its own flight's clock, one shared y-scale across all three. The distance between each estimator's own live position estimate and the drone's true position, millimetres, against time; shaded bands mark when the occluder covered the wall tag. This is each estimator's own error against ground truth, not the registered hold error (ground truth's own distance from the hold target). Each panel shows only that flight's scored span, from the start of its first hold window to the end of its last tag-loss window, so take-off, the approach to the hold point and the landing are left out.
