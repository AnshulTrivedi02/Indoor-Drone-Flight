E05. Experiment 5 (tag hold): each flying estimator's own distance from ground truth over time, occluder intervals shaded.

Experiment 5 (tag hold), one flight per flying estimator: EKF3 in blue, UKF in teal, FGO in orange, each on its own flight's clock, one shared y-scale across all three. The distance between each estimator's own live position estimate and the drone's true position, millimetres, against time; shaded bands mark when the occluder covered the wall tag. This is each estimator's own error against ground truth, not the registered hold error (ground truth's own distance from the hold target), because the lateral moves built into the hold profile are far larger than this millimetre-scale effect and would hide it if positions were plotted directly. The line moves away from its settled level during a shaded band and returns to it once the occluder is removed, though not always in the same direction. Each panel starts shortly before that flight's first steady hold period, leaving out the initial climb and approach to the hold point.
